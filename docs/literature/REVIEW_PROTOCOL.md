# LR0 review protocol

## Questions
1. Which physical models and solver methods are suitable for each laboratory?
2. Which current standards and OEM inputs are required for the 110/20/0.4 kV campus?
3. Which independent benchmarks qualify the methods, and where do they fail to support design claims?
4. Which modelling assumptions should be revised, and how will evidence close them?

## Search and inclusion
Targeted web searches on 26 November 2026: Newton-Raphson power flow/MATPOWER/pandapower; CIGRE TB 575 and 906; IEC 60909 2016/2026; IEC 60255-151 and IEC 60947-2; CT158 worked case; transformer earthing/zero sequence and thermal rating; IEC 60287; STAMFORD alternator data and Schneider selectivity; PSCAD residual flux; ANDES and IEEE stability classification; ENTSO-E/NERC large loads; ASHRAE data centres; Uptime topology; ISO/IEC PUE. Prioritised original publishers, standard bodies, utility organisations, scholarly papers and OEM data over reseller copies. Selected records with direct implications for modelling and verification. Search was purposive, not exhaustive; no invented PRISMA flow counts or claim of dual screening.

Record bibliographic identity, edition, access depth, source link, technical conclusion, project applicability and limitation. Differentiate standard scope from mandatory clauses, publisher claims from independent findings, and source-derived facts from engineering inference. Catalogue/abstract cannot support detailed implementation requirements. Vendor figures and copyrighted standards not republished.

## Next systematic pass
Search IEEE Xplore, IET, ScienceDirect, Springer, OpenAlex and engineering libraries with reproducible query strings for each topic. Record search date, corpus, deduplication, inclusion/exclusion and reviewer decisions. Retrieve lawful full texts; evaluate evidence by model fidelity, measurement vs numerical reference, reproducibility, uncertainty and applicability to 50 Hz mission-critical networks. Include opposing methods and failed cases. Prefer original data and peer-reviewed research for quantitative claims. No target paper count substitutes for relevance.

Proposed screening exclusions: purely marketing claims, untraceable numerical values, incompatible system frequency/voltage without conversion, duplicated records, studies with no relevant method/evidence. Keep rejected items in a log rather than discarding inconvenient findings. Review categories: analytical/benchmark, empirical/field, standard, vendor specification, software documentation, engineering synthesis. Different categories serve distinct purposes.

## Completion gate
LR0 initial synthesis is ready for review; full LR0 closure requires the P0 decisions in the decision register to be resolved for the particular next study, verified source clauses where needed, independent reproduction of reference cases and parameter provenance. The broader review remains a living programme, not a deadline.
