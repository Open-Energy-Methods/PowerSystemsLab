# Theory curriculum

For each topic: define quantities and SI units, derive equations with assumptions, solve a worked example, identify limiting cases, then implement and test.

| Domain | Essential theory |
|---|---|
| AC fundamentals | RMS vs peak, complex impedance, conjugate complex power, three-phase line/phase quantities, Fourier series |
| Per-unit | Sbase, Vbase, Ibase, Zbase, transformer base changes |
| Networks | Kirchhoff laws, nodal admittance, slack/PV/PQ buses, reactive limits, AC power balance, Jacobian, conditioning |
| Equipment | equivalent circuits, copper/core losses, thermal ratings, transformer vector groups, sequence impedance, machine dq models |
| Faults | symmetrical components, positive/negative/zero sequence, equivalent source, voltage factors, peak/breaking/thermal duties |
| Protection | pickup, CT ratio/saturation, inverse and definite time, directional/differential/distance concepts, coordination tolerances |
| Dynamics | swing equation, inertia, damping, equilibrium, eigenvalues, governors, excitation, voltage and frequency recovery |
| EMT | differential algebraic equations, timestep convergence, R-L offset, magnetic saturation and remanence, travelling waves |
| Electronics | switching and averaged models, PWM, DC links, current limits, harmonics, PLL, grid-forming/following |
| Operation | constrained optimisation, feasibility, dispatch, OPF, contingency constraints, observability |
| Reliability | topology and dependencies, availability vs service continuity, maintenance, restoration, failure distributions |
| Digital | measurement sampling, phasors, time sync, protocol semantics, simulation vs real-time HIL |
| Thermal | energy conservation, heat transfer, thermal networks, load cycles, uncertainty |

Mandatory distinctions: RMS versus EMT, initial versus sustained fault current, verification versus validation, generic versus real equipment, and educational screening versus compliant engineering design.
