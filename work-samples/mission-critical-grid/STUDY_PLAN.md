# Work sample study plan

No deadline. The scope is selected to demonstrate transferable consultancy skills in data-centre electrical power systems. Commercial software is a qualified extension, not an excuse to delay or overclaim the open core.

| Gate | Study | Required evidence |
|---|---|---|
| W0 | Qualification | Pinned pandapower; two-bus hand case; CIGRE MV regression; CT158 access and compatible method |
| W1 | Design basis | Bottom-up load register; equipment candidates; earthing; interlocks; electrical SLD; assumptions and source provenance |
| W2 | AC load flow | Base and operating modes; power balance; bus voltage; branch loading; P/Q and losses |
| W3 | Contingencies | Initial, isolated, transferred and restored states; served IT and cooling; no implied uninterrupted service |
| W4 | Fault analysis | IEC 60909 max/min three-phase and supported asymmetrical faults; branch currents; utility duties; generator restrictions |
| W5 | Protection | Relay integration under variable current; representative device curves and selectivity tables; inrush and withstand; generator decrement |
| W6 | Resilience | A/B paths for every block; shared dependencies, maintenance, standby fuel and UPS autonomy assumptions; failure modes |
| W7 | Alternatives | Coupler policy, transformer impedance, standby rating and design trade-offs |
| W8 | PowerFactory | Legitimate licence and publication permission, independently entered model, aligned comparison settings and discrepancies |
| W9 | PSCAD | Free-edition-compatible RL fault and transformer energisation; analytical/reference checks and time-step sensitivity |
| W10 | Advanced | Generic RMS load acceptance; cooling restart and thermal/UPS energy sensitivity |
| W11 | Release | Traceable result tables, engineering report, limitations, reproducibility and reviewer findings |

## Competency mapping
- Electrical distribution: W1–W3.
- Network analysis: W0, W2–W4, W8.
- Protection principles: W4–W5, W9.
- Reliability and resilience: W3, W6, W10.
- Engineering optimisation: W7.
- Multidisciplinary design: cooling, UPS and standby generation in W1, W6, W10.
- Technical communication: SLD, evidence register and W11.

## Acceptance policy
Use the parent verification protocol; set tolerances before runs. Distinguish numerical verification from physical validation. Generic equipment is not certified equipment. Report failed cases and all unsupported outputs. PowerFactory results remain private unless permission is established. No application-ready claim until W0–W7 and the core W11 report have passed independent review; advanced claims only after their respective gates.
