# PowerSystemsLab

**Open Energy Methods | From first principles to industrial power systems**

An independent computational and experimental learning programme in electrical power systems engineering. The aim is transferable competence, not a job-specific demonstration or a collection of software tutorials.

**Status:** Foundation stage. No qualified numerical or physical results are claimed.

The first flagship application is [MissionCriticalGrid](applications/mission-critical-grid/DESIGN_BASIS.md), a synthetic data-centre campus. Other applications may include industrial networks, turbine-generator systems, renewables, HVDC, storage and microgrids.

Each module progresses through theory, analytical calculation, implementation, independent checking and an oral explanation by the learner. AI-assisted work is recorded; passing software tests alone does not establish personal competence.

Commercial software access and publication permissions must be established before restricted assets or results enter this public repository. No client design, standards compliance, certification or professional approval is implied. Project licensing is pending maintainer selection; third-party rights remain separate.
